# Motivational Quote

A simple motivational quote desktop application built with Python, PySide6, and SQLite.

## Features

* Show motivational quotes
* Randomly select a quote
* Store quotes in SQLite
* Simple graphical interface

## Technologies

* Python
* PySide6
* SQLite
* Qt Designer

## How to Run

```bash
pip install PySide6
python main.py
```
